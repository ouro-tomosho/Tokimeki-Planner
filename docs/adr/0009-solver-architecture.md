# ADR-0009：求解器是构造式启发式，判定器是唯一口径

**Status**: accepted（2026-10-09 所有者裁决）
**取代**: ADR-0008「内联 HiGHS」（该文已删除，其内容并入本文的历史一节）

## 决策

1. **求解器只有一个：构造式启发式**（`src/descent.js`）。它按**整条时间轴**一次性分配决策，
   逐槽最速下降 + 迭代局部搜索，固定种子、固定工作量档位。
2. **判定器只有一个：`plan()`**（`src/plan.js`）。求解器的自评只用于搜索排序，**不是结论**；
   界面、测试、求解器收尾都用同一个 `plan()`。
3. **精确求解（HiGHS MILP）与内联它的整条构建管线全部移除**：`src/milp.js`、`src/highs.js`、
   `src/chunks.js`、`tools/inline-highs.mjs`，以及构建期的三处改写与相关的零外链守卫。

## 依据：精确求解从来没有赢过

精确求解（三片固定分片 + 片内 8 周块严格滚动）曾与启发式**并列产出候选**，由 `plan()` 按
"合格性 → 全局约束达标数 → 小目标达标数 → 结局达标数"取优。实测（预算 60 s／场景，判定器 `plan()`）：

| 场景 | 启发式候选 | 精确求解候选 | 胜者 |
| --- | --- | --- | --- |
| 默认输入 | valid，全局 4/4，小 2/2，结局 **9/9** | valid，4/4，2/2，结局 8/9 | 启发式 |
| 成功率 35% | valid，4/4，2/2，结局 **7/9** | valid，4/4，2/2，结局 4/9 | 启发式 |
| +新增小目标（社团经验 ≥410） | valid，4/4，3/3，**9/9** | valid，4/4，3/3，8/9 | 启发式 |
| 结局目标随机调低 | valid，4/4，2/2，**9/9** | valid，4/4，2/2，8/9 | 启发式 |

精确求解**一次都没赢**，而代价极高：

| 产物构成 | 字节 | 占比 |
| --- | --: | --: |
| plan-core（全部源码 + 规则） | 145,408 | 2.8% |
| **内联 HiGHS（JS 胶水 + base64 WASM）** | **4,878,230** | **94.1%** |
| worker 引导 + 应用 | 74,829 | 1.4% |

移除后 `index.html`：**5,187,075 → 254,495 字节（−95%，小 20 倍）**，且少了 830 行求解器代码、
3.9 MB 的开发期依赖，构建管线不再需要"把二进制烤进产物"的三处改写。

这也是"排布器对体面负责、判定器对真实语义负责"（ADR-0007）的彻底落实：**能找解的不需要证明，
能证明的不需要找解**——既然判定器已经用真实引擎逐日复核，求解器只要找得够好就行。

## 优先级口径（求解与判定必须一致）

**全局约束 → 小目标 → 结局目标**，严格分层、层与层不共享刻度：

① **始终没达成的全局约束条数**（二元）→ ② 已达成后被跌破的天数 → ③ 小目标未达标条数与缺口
→ ④ 结局目标未达标条数与缺口 → ⑤ 尚未达成的天数（"尽早满足"，仅作层内细化）→ ⑥ 跌破幅度
→ ⑦ 夹逼吸收。

### 三个必须记住的坑

1. **取优口径漏了全局层**：候选取优曾写成"合格性 → 小目标 → 结局"，**没有比全局约束**。
   结局目标一放松，启发式候选就去多追一条结局目标、放着一条全局约束没达成
   （实测 `gc-popularity` 只有 **26.1/100**），而它在"结局达标数"上更多，于是被选中——
   直接违反优先级。**注意 `plan()` 的 `valid` 只管"达成后有没有跌破"**，全局约束始终没达成时
   `ok=false` 而 `valid=true`，所以只看 `valid` 是抓不到它的。
2. **启发式自己的评价口径同样漏了全局层**：旧序是"未达标条数 → 缺口 → 全局违反 → 夹逼吸收"，
   而 `else if (g.hard)` 让**从未达成的全局约束完全不进目标函数**。后果：放松结局目标时
   人缘停在 91（要求 100）而搜索毫无察觉；35% 成功率下给出 **1161 天硬违反、全局 0/4**。
3. **① 必须写成"二元条数"，不能写成"未达成天数 × 大权重"**：试过那种写法，"
   让人缘早一天达标"会盖过全部结局目标，局部搜索于是靠不停聊天把达标日往前挪，把运动与毅力
   整条饿死（实测运动 **0/130**、毅力 15.7/100，人缘被刷到 196）。"尽早满足"只能是层内细化。

4. **搜索必须尊重使用者钉住的槽位**：`plan()` 里**钉住优先于求解器的填空**（`calendar.js` 的
   `resolveCommand`），所以搜索的候选必须把使用者钉住的那一条作为**唯一**候选——否则它优化的
   根本不是最终那份日程。这条从旧实现起就一直漏着（2026-10-09 追查新规则时才发现，见下）：
   实测钉住 `1995-04-23 = cmd-rest` 时搜索照自己的选择按 `cmd-chat` 推进，到 11 月与真实轨迹
   已差 **9.5 点人气**，最终交出一份 `valid=false`（全局约束破线 2 天）的日程，而搜索层自评
   **完全看不到**。`skippedDays` 与"显式清空"的日子由 `isSettled` 排除，不受影响。

5. **首次社团规则的集训周豁免**：集训周强制社团指令，而若"已玩到"落在集训周中间，本时间轴上
   第一个社团指令**必然**是工作日——两条规则会互相判死。所以首次社团规则只管**自由选择**的
   社团指令，强制执行的既不算合规也不算违规。**这是对所有者规则的解读，需要确认。**

### 协作式取消

搜索整体是同步的（14–21 s），而 Worker 收到的取消消息是**宏任务**：不让出事件循环，
`shouldStop()` 在整个搜索期间永远是假，取消按钮等于失效。所以每次全槽下降之后、每轮 ILS 之前
都要让出一次宏任务并查一次标志——实测取消延迟从"整段跑完"降到约 5 s（预算 20 s）。

## 三条不可让步的纪律

1. **对外结论一律来自 `plan()`**，不来自搜索层自评。
2. **搜索与复核必须用同一份有效规则**（`withSuccessRate`）：开发期实测踩过——测试用原始规则
   （35%）喂搜索、却用 `plan()` 按输入里的 70% 复核，两边不在同一个世界，结论全是假的。
3. **无兜底**：求解抛错就抛中文错误，由界面现有的错误面显示，不静默降级。

## 规则：第一次执行的社团指令必须是周日的日指令

所有者 2026-10-09 加的两条规则（数据见 `data/rules.json` 的 `clubUnlockDate` 与
`clubFirstCommand`，说明见 `RULES.md`）：

1. 社团指令只能在 **1995-04-09 及之后**执行——这条原本就有（`clubUnlockDate`，由
   `clubBlockReason` 把关：解锁日之前社团指令不结算，且**不算违规**）。
2. **第一次执行的社团指令必须是周日的日指令**——休息日只会解析到日指令，而周日按定义就是
   休息日，所以判定就是"第一个社团指令所在的那天是不是周日"。

判定在 `plan.js` 逐日标注 `clubFirstViolation`（违规天 = 合规的首次执行出现之前、所有落在
非周日的社团执行），`checkpoints.js` 汇总成 `clubFirstViolations` 并计入 `valid`。
搜索侧在分层评价里紧跟"全局硬违反"之下加了同一层——**求解与判定必须同口径**，否则求解器会
搜出一份判定为不合格的日程。

## 历史（已移除方案的记录，避免重走）

- **精确求解时代的装置**：三片固定分片（52/52/48 周，从时间轴起点起算）、片内 8 周块、
  块尾余量（软偏好，保证下一块还有守住全局约束的机动空间）、逐块重放闸门（模型声明值 vs
  真实引擎，容差 1e-6）、模型 ↔ 穷举等价套件（6/6，重放偏差 ≤ 1e-13）。
- **两个把模型写错过的坑**（都是重放闸门抓出来的）：夹逼阈值误用"被迫全局约束的下界"而不是
  属性边界；`g`（"第 i 天首次达标"）曾写成自由变量，使模型能"先达标再跌破却声称从未达标"。
- **52 周不可解**：约 4700 个 0-1 变量时 60 s 连一个可行解都找不到，8 周块约 475 个变量能在
  1.1 s 内证明最优——这是分块的由来，也是"跨期容量分配丢失"的根源。
- **毅力调参复核**：逐档试过九种权重方案（含去掉块尾余量、预算×4、把结局层抬到全局之上、
  把进度写成硬约束），结论是**权重不是杠杆**——真因是分块滚动丢掉了跨期容量。旧启发式在
  整条时间轴上一次性分配，15 s 就能拿到含毅力 100 的 11/11；这也是"回到启发式"的直接证据。
- **结局层跨块整体重排**（两遍滚动 + 高层钉成硬约束）实测无效：与第一遍持平甚至更差
  （第二遍加毅力进度硬底时 20 块里 12 块被迫降级、228 天破线），已回退。
