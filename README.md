# Tokimeki-Planner

《心跳回忆·永远属于你》（1995）的日程规划工具：在固定的时间轴上安排每周指令，使十项属性在毕业时达到指定目标。它完全在浏览器里离线运行，不读写游戏存档，也不发起任何网络请求。打开网页就能用，不需要安装任何东西。

---

## 使用说明

界面分三块：左边输入，上面工具栏，中间日历与检查点清单。

### 左栏：起点状态

| 控件 | 说明 |
| --- | --- |
| **已玩到** | 你在游戏里已经玩到的那一天，同时是时间轴的起点。这一天不结算——它的结果已经发生在游戏里。规划从它之后开始，终点固定为 1998-03-01。 |
| **当前属性** | 起点那一刻的十项数值，可在格子里直接改。十项包含**当前社团经验**。 |
| **起始社团** | 起点时加入的社团，默认管乐社；也可以选「未加入」。社团只能在周日切换，切换后自该周日起生效。 |

### 工具栏（右上角）

**计算**：按当前输入求解一份排程。改动只会标记「N 处改动待计算」，点「计算」才开始；求解期间显示进度与已用时间，可随时取消。求解用**构造式启发式**（按整条时间轴一次性分配决策），结果交给**判定**用真实引擎逐日复核之后才算数。目标按**严格优先级**排：先守住全局约束（一旦达成便不得跌破），再满足小目标，最后才追结局目标。

**导入 / 导出 JSON**：导出把当前输入存成一个 JSON 文件（文件名就是你标记的「已玩到」日期）；导入把它读回来。输入会自动保存在本机，刷新或关掉再打开都还在；计算结果不保存。

### 日历

一行是一个自然周，两个自然月并排。

- 每个格子里写的是**当天实际执行的指令**——不用心算「这周跑的是什么」。
- 格底状态一眼可分：平日 / 周日 / 休息日 / 空过 / 已玩到。
- **周指令**作用于该周全部平日；**休息日**（周日，以及一批游戏内固定的节假日）执行自己的日指令。
- **小目标**在它的落点日有一枚标记；全局约束与结局目标在检查点清单里看。
- 翻页（上月 / 下月）、日期选择器、跳到起点 / 跳到终点，可在整条时间轴（1995-04 → 1998-03）里移动。
- 周日与休息日的日期数字是红色的，一眼可见一周里哪几天要单独下指令。

### 选中某一天

点一个格，正下方显示那一天的详情：日期、星期、第 N 周、当天执行的指令及其来源（日指令 / 周指令 / 空过），以及当天结算后的十项属性值。

**框选**：从一格拖到另一格，按日期连续取范围，跨周跨月都成立。

**右键日期格**打开操作菜单：指定指令、切换社团（仅周日）、设为 / 取消休息日、跳过 / 取消跳过、添加检查点、管理这一天的检查点、设为已玩到。按 `Esc` 或点别处关闭；`Shift+右键` 放行浏览器原生菜单。

在**平日**上改指令等于改**本周的周指令**——选区碰到某周的任何一天，那个周的周指令就改；改完本周全部平日会亮一下。

「设为已玩到」会把时间轴起点推到那一天：起点、当前属性、起始社团与社团经验一起对齐到「那一天结算之后」。属性按游戏口径向下取整，之后可以手动改（游戏里有成败随机，实际值可能与计划值不同）。

### 检查点清单

清单分成三部分：

| 分组 | 含义 |
| --- | --- |
| **结局目标** | 落点是时间轴终点（1998-03-01），逐项检查九项属性是否达到阈值。**社团经验不在其中**——它不随毕业结算，所以没有结局目标；这一组的九行固定存在，不能增删。 |
| **小目标** | 落点是各自的截止日，检查所选**属性集合的求和**是否达到阈值。按截止日先后排列。 |
| **全局约束** | 需要全程守住的下限或上限，每个结算日检查一次：达成之前只算「欠着」，一旦达成，此后任何一天跌破都算「已破线」。 |

每一行显示属性、阈值、当前值与差距，行内即可编辑；小目标与全局约束还会显示落点（结局目标的落点固定，不重复显示）。判定有三种状态：**达标** / **还欠着**（尚未达成）/ **已破线**（达成过又跌破）。

状态栏给一个总判定：**是否达标**。

排不出全部达标时，工具不猜原因：状态栏如实显示未达标，检查点清单逐条给出哪一项没达到、还差多少。

同一份输入连续计算两次，**结果完全相同**：求解器的随机种子、槽遍历顺序、工作量档位都是固定的，与机器快慢无关。判定一律以检查点清单的读数为准。
