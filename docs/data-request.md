### 这张表怎么来的

表里的数字是**反解**出来的，不是直接观测到的：所有者提供的是「**三周内把同一条指令同时作为周日日指令与本周指令**」的九项属性三周总变化量（21 次执行 = 3 个周日 + 18 个平日）。反解严格照抄结算规则：

- **正向属性、成功时上升**：三周总量 `T = c × 0.815 × (3b + 18)`，其中 `0.815 = 0.63 + 0.37/2`（成功取满、失败减半），`b = 4`（日常指令）或 `6`（社团指令）。除数：日常 **24.45**、社团 **29.34**、休息指令（永不失败）**30**。
- **正向属性、成功时下降**：休息日不加成、失败也不打折 → `T = 21c`，除数 **21**。
- **压力**：失败取成功时的原值再 +1 → `T = 21 × (c + 0.37)`，即 `c = T/21 − 0.37`；「休息」的下降在休息日 ×4 且永不失败 → 除数 **30**。
- **取整**：对精确值**向下取整到 2 位小数**。

**为什么必须把失败分支算进去**：三周数据里的**下降项**恰好按 ÷21 复现换表前的旧表（`-17/21 ≈ -0.81`、`-52/21 ≈ -2.48`、`-14/21 ≈ -0.67`）。若不计失败分支，这些会变成 ÷13.23，与旧表差一倍。

**精度边界**：压力列是"假精度"。`c = T/21 − 0.37`，整数总量每差 1 就使系数差 **0.048**，所以 `0.01 / -0.04 / -0.14` 这类值都落在噪声内（「和同学闲聊」「运动」「棒球社」「游泳社」四格因此翻符号）。其余八项属性可信：用取整后的表回放三周，预测总量与实测最大只差 **0.26**。

**实测数据只处理一次**：不随新数据反复更新，因此不写派生脚本，结果直接进数据文件，算式记在这里。

## 4. 已经定型的规则（请核对，不需要你提供数据）

### 结算

- 内部采用**定点整数**，缩放因子 `1e6`。
- 每一天：应用当日指令效果 → **向下取整** → 夹在 `[0, 999 × 1e6]`。
- 终点 1998-03-01 不结算，最后结算日为 1998-02-28；起点为 1995-04-04 时当日不结算。

### 成功率与失败

- 每条指令一个成功率字段（当前 17 条全为 **63%**），平日与休息日相同。
- 期望值 = `成功率 × 成功变动 + (1 − 成功率) × 失败变动`，确定性计算，不做随机模拟。
- 失败时的变动：成功时**上升**的**正向**属性幅度**减半**（在休息日加成**之后**减半）；成功时**下降**的属性**照常下降**；**压力不参与减半**——按其成功时变动的**原值**保留，并**额外 +1**。
- 例：「研读文科」成功时压力 `+0.8`，失败时压力 `+0.8 + 1 = +1.8`；「培养艺术气质」成功时压力 `-0.3`，失败时压力 `-0.3 + 1 = +0.7`。
- **休息指令不参与成功率判定，永远成功。**
- 社团经验不受成功或失败影响。

### 休息日加成

- 休息日执行时：日常指令上升效果 ×4、社团指令上升效果 ×6。
- **负面指标（压力）不受 ×4 / ×6 加成。**
- 休息指令是唯一一条负面指标下降效果在休息日 ×4 的指令。

### 决策结构

- 决策单位是**周**，结算单位是**天**。
- 一个自然周 = 周日（第 1 天）+ 平日（周一至周六）。
- 决策顺序：周日日指令决策 → 周日结算 → 本周周指令决策 → 各平日依次结算；本周内被标记为休息日的日子，在**该日结算之前**先做它的日指令决策。
- 首周没有落在时间轴内的周日时，周指令决策落在**首周第一次结算之前**。
- 平日不单独决策，一律执行本周周指令。
- 周指令与日指令的候选池**都是全部 18 条**（再受解锁日、互斥、社团约束）；社团指令自 1995-04-09 起可选。
- 空过（跳过）的周/日**不执行任何指令、不判定成败、也不结算**——属性原样带入下一天。**（已确认）**

### 目标函数

1. 全部硬约束达标（全局约束、小目标、结局目标）；
2. 正向属性**等权总和**最大化；
3. 负面指标（压力）最小化。

详见 [ADR-0002](adr/0002-objective-layered-equal-weight.md)。

### 用户操作（工具不得修改）

- 切换社团（只在周日，自该周日起生效，可影响该周日的日指令）、指定休息日、指定周指令或日指令、跳过。
- 任一操作后，从**下一个决策点**起重规划，之前的安排保持不变。

### 输出

规划结果表：每周的周指令、每个休息日的日指令、每一天结算后的属性。
