# Tokimeki-Planner

《心跳回忆·永远属于你》（95 版）的日程规划工具。帮你在固定的三年时间轴上排每周指令，让十项属性在毕业时达到目标。

纯前端单文件，**双击就能用**：不联网、不安装、不读写游戏存档。

## 三步开始

1. **打开** `index.html`（双击，或访问 [在线版](https://ouro-tomosho.github.io/Tokimeki-Planner/)）。
2. **填左栏**：「已玩到」填你在游戏里实际玩到的那天；「当前属性」填那天的十项数值；「社团」选当前社团。
3. **点右上角「计算」**，等 10–20 秒，日历会被排满指令。

> 改任何输入都不会自动重排，只会标记「待计算」。改完记得再点一次「计算」。

## 界面速览

| 区域 | 看什么 |
| --- | --- |
| 顶栏 | 状态徽章（尚未计算 / 达标 / 未达标）+ 计算、导出、导入 |
| 左栏 | 已玩到、当前属性、当前社团——这里是你的输入 |
| 日历 | 两个月并排，从周日排起，**一行 = 一周**；格子里是当天执行的指令 |
| 详情条 | 点任意一天，看它的指令、结算状态、活动与十项属性 |
| 检查点 | 三条结论并排：结局目标 / 小目标 / 全局约束，缺多少一目了然 |

颜色含义在图例里：平日、周日、休息日、跳过、小目标截止、已玩到。

## 改某一天的指令

**右键日期格 → 「指定指令…」**，选一条指令，确定。

- **改平日会连带整周**：平日执行的是「本周指令」，所以改一天等于改那一周的所有平日。详情条会提示影响范围。
- **框选一段日期**：从一个格子拖到另一个格子，可以批量指定。
- **这些天改不了**（右键菜单里的「指定指令…」是灰的）：
  活动日、社团加入日、社团切换日、体育类社团每月第 3 个周日——它们的指令由日历和社团规则决定。
- **打电话/约会**不会自动排进日程，只能你自己右键指定；而且**只在休息日可用**。

## 结局目标没达标？

检查点表会告诉你每条差多少（「差距」列）。

- 缺口是**真实容量问题**，不是 bug：默认数据下求解器能达成全部目标，但如果你改过目标或属性，可能就排不出来。
- **小目标优先于结局目标**：两者抢天数时，结局目标先被牺牲。
- 属性会随游戏里的随机事件漂移，建议**每三个月**回到游戏核对一次「已玩到」与属性，再重算。

## 目标（检查点）

检查点表里点「+ 加一条」新增，点 ✎ 编辑，点 × 删除。

左栏的**「快速添加小目标」**预置了圣诞节、练习比赛、大赛、出路等常用目标：下拉选一个，点「确认」即可加入，不用手填日期和公式。已在表里的同一条不会重复添加。

同日同属性上互相矛盾的目标（如 `容姿 < 70` 与 `容姿 ≥ 90`）会显示**已冲突**，不参与求解与达标判定——加了就能看见，不必先计算。

| 类型 | 落点 | 说明 |
| --- | --- | --- |
| 结局目标 | 毕业时 | 固定九项属性各一条，**不可删除** |
| 小目标 | 指定日期 | 可以是多个属性的**求和**，也可以是「指令使用次数」 |
| 全局约束 | 每个结算日 | 每天都要守住，跌破一次即「已破线」 |

## 保存、导出与导入

- 输入会**自动存在浏览器里**，刷新后还在（只存输入，不存计算结果）。个别浏览器用 `file://` 打开时不允许本地存储，那就靠「导出」留档。
- 「导出」得到一个 JSON 文件；「导入」读回同一份文件，可以在另一台机器上接着用。
- 结果不会导出——它是算出来的，随时可以重算。

## 数据来源

全部领域数据（属性、指令、社团、阈值、固定日历）**由仓库所有者手工录入并确认**。权威副本是 `data/rules.json`，可读版本见 [RULES.md](RULES.md)（时间轴、结算规则、指令效果表、固定日历）。

本项目**不引用任何其它项目的领域数据、术语表、公式系数、算法选型或设计文档**，也不读写游戏存档。详见 [ADR-0001](docs/adr/0001-clean-room.md)。

## 开发者

```bash
npm run build     # 从 web/ 与 src/ 生成 index.html 与 plan-core.js
npm run verify    # 校验磁盘产物 == 一次新鲜构建
```

- 改界面改 `web/`，改算法改 `src/`，改数值改 `data/rules.json`；**根目录 `index.html` 是产物，不要手改**。
- `RULES.md` 与 `README.md` 一样是手写文档，不参与构建。
- 术语见 [GLOSSARY.md](GLOSSARY.md)，决策见 [docs/adr/](docs/adr/)。
