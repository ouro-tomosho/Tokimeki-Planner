# 领域输入的来源边界（清洁室）

**Status**: accepted

## 决策

`Tokimeki-Planner` 的全部领域数据与领域术语只来自项目所有者本人。本项目不引用任何其它项目的领域数据、术语表、公式系数、算法选型或设计文档——无论那些项目是否属于所有者本人。本项目也不读写游戏存档。

## 背景与理由

本项目与所有者既有的若干游戏工具题材相近（既有的日程工具仓库、游戏目录下的存档工具脚本）。复用既有资产在短期内更快，但所有者明确要求一个干净、完全由自己掌控的项目，因此选择隔离而非复用。

## Considered Options

- **复用既有仓库的领域模型与规则数据**：短期最快，但会把既有的建模产出（数值表、系数、术语、算法选择）带入本项目，与本决策冲突。
- **只复用"游戏常识"、隔离建模产出**：边界依赖个案判断，不可审计。
- **完全由所有者提供数据（本决策）**：边界清晰、可审计，代价是数据重新推导与重新录入。

## Consequences

- 所有领域数值与术语以所有者提供的资料为准，逐条可追溯。代理人与协作者不得从任何其它项目推导或补齐缺失数值。
- 若要引入任何领域术语或数值，须先给出待签清单，经所有者批准后方可写入本仓库。
- **缺失数据是"等待输入"的状态，不是可以推断填空的状态。**
- 游戏存档不是本项目的输入，也不是输出。存档解析、校验与写回均不属于本项目的范围。
- 因此本项目不需要、也不应包含任何存档格式相关代码或知识。
